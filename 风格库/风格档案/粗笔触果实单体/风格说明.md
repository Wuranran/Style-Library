# 粗笔触果实单体

饱满的有机大轮廓里保留粗笔触。果实外形用平面色块概括，内部用相邻色叠擦、长笔拖痕和局部擦痕建立厚薄与方向。用户提供的六张南瓜海报共同支持这一观察。红美人柑橘案例把这套表现移到一颗橙红果实上，短果梗与深橄榄绿叶保留为少量辅助形。

> **字体风格提取未成功。** 本档案只总结插画单体，字体未总结、未收录。

| 要保留的关系 | 可以随题材调整 |
| --- | --- |
| 轮廓大而可辨，主体由色块与外围空间分开 | 果种、轮廓形状、正侧视角、整果或切面 |
| 表面保留明显的方向性干刷和同类色叠涂 | 笔触方向、橙绿等具体色系、果皮主色 |
| 细节集中在果实，果梗和叶片简化 | 果梗、叶片的数量和位置 |
| 质感留在颜料层，透明图的外围干净 | 平面版式可使用浅色留白，单体资产保留透明背景 |

画法的可见描述是干刷叠色、厚薄不一的色层与手绘擦痕。原照片支持这类视觉判断，具体颜料媒介待确认。
