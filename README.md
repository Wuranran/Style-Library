# 风格分析与克隆系统

从一张喜欢的基准图出发，比较相似图与对照图，提炼能跨题材复用的视觉规则。调用同一版风格时，系统会适配新主题，并给出中文 JSON、英文 JSON、中文简易提示词和完整自然语言提示词。

## 启动方式

| 场景 | 用法 |
| --- | --- |
| 网页版模型 | 下载 [START.md](START.md) 并上传，说「启动风格分析和克隆系统」。建库时附图，调用已有风格时附风格档案或提供可读取的链接。 |
| GitHub | 让模型读取本仓库的 [START.md](START.md) 并启动。要复用某个风格时，指定名称、别名或版本。 |
| 模型记忆 | 在支持记忆的模型中保存常用风格的别名、档案链接和版本。以后直接说「用木版画雨景做一张……」，模型从 [风格索引](library/index.json) 定位档案。当前能够读到规则后即可应用。 |
