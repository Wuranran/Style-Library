# 木版画雨景

[当前档案 v1.0](versions/v1.0.json) 以歌川广重《大桥安宅骤雨》为基准，范围为这件作品启发的竖幅环境雨景。已有一次参考图辅助的主题迁移。后续可加入不同题材的版画作为相似图和对照图，用来验证规则是否能跨作品成立。

## 可改清单

| 类别 | 可用判断 |
| --- | --- |
| 直接可换 | 人物、道具、时代、地点、载具以及角色人数 |
| 需要接住原作用 | 斜向路线可以由桥、山路或沿岸街道承担。连贯水面可由低细节山谷接替。局部暖色可由衣物、窗光或路灯承担。 |
| 当前优先锁定 | 细雨线贯穿空间，冷色连续环境占主导，斜向路线组织小尺度主体，远岸省略描绘，细墨轮廓和平涂套色。 |
| 待确认 | 晴天等跨天气变体、雨线是否必须有双角度、极宽画幅下的辨识度。 |
