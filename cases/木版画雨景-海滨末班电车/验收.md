# 成图验收

实际查看 [本次成图](results/seaside-tram.jpg) 后，记录如下。

| 检查 | 结果 | 画面依据 |
| --- | --- | --- |
| 空间与尺度 | pass | 斜向石岸街路切入开阔港湾，一辆小尺寸电车可辨，远岸为低矮剪影。 |
| 主体与规格 | pass | 可见一辆电车和三位持伞行人。生成图为 1024 × 1536。 |
| 雨线 | pass | 细雨线跨越天空、水面与近景。两组雨线的角度差在预览中不够显著。 |
| 暖色控制 | fail | 窗光形成焦点，路面与伞面有较强暖色，超出窗光局部。 |
| 纸面与平涂 | fail | 下半部的铺地、石墙与雨纹比基准图更密，纸面颗粒较重。 |
| 系列一致性 | not_applicable | 本案例是一张图。 |

这次生成验证了新题材中的斜向路径、环境尺度、冷色水域以及贯穿式雨线。按更加贴近原作的平涂效果验收时，暖色范围和纹理强度仍需收敛。

下一次定向修订可使用这一句。近岸路面以两三块浅赭灰平涂呈现，车窗保留局部暖光，路面反光压低。复核时同时检查轨道方向、电车与三位行人以及空间纵深。当前记录的是实际首轮成图。
