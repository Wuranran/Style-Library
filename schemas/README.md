# JSON 字段规范

- [风格档案 Schema](style-profile.schema.json) 定义参考说明、带证据的视觉规则和可改清单。可对照 [木版画雨景 v1.0](../library/styles/木版画雨景/versions/v1.0.json)。
- [任务 Schema](image-task.schema.json) 定义主题、锁定项、适配记录、四版输出、实际执行和验收。可对照 [末班电车任务](../cases/木版画雨景-海滨末班电车/任务.json)。

两份 Schema 使用 JSON Schema Draft 2020-12。双语语义一致与图像视觉结果由任务验收记录。
